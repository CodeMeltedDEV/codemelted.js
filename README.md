"Write once, run anywhere (WORA)" was the famous slogan made by Sun Microsystems in 1995. At the time, this technology allowed for easy full stack engineering allowing you to target dedicated workstations and on premise servers. So long as a Java Runtime Environment existed, you could run your code. Java was unable to keep to their slogan as web browsers became more advanced, mobile devices became ubiquitous, and companies no longer required dedicated servers.

The **codemelted.js Project** aims to give software engineers the ability to deliver on this full stack engineering premise. This will be accomplished via two overly engineered modules. The `codemelted.js` ES6 module will deliver the frontend side of the stack by allowing quick development of Single Page App (SPA) / Progressive Web App (PWA) web stack solutions. The `codemelted.rs` will provide the backend native piece. Written in Rust, it will provide both a consumable crate to aid in building custom native solutions along with delivering the `codemelted` Command Line Interface (CLI).
